# Alfursan Academy
Full-stack web application for Alfursan Football Academy, built with Next.js 16 (App Router), Tailwind CSS v4, Prisma, Neon PostgreSQL, NextAuth.js, and ImageKit.

## Getting Started

1. Set up the database:
   ```bash
   npx prisma generate
   npx prisma db push
   npx prisma db seed
   ```

2. Run the application
   See NextJS docs.

## Admin Area
Access the admin dashboard at `/login` using the credentials provided to you.
