==============================================================
موقع أكاديمية همة الفرسان الرياضية — دليل سريع
==============================================================

محتويات المجلد:
  index.html      الصفحة الرئيسية
  nuzhah.html     صفحة فرع النزهة
  buhayrat.html   صفحة فرع البحيرات
  js/data.js      ⭐ ملف البيانات — كل التعديلات تتم هنا
  js/main.js      منطق الموقع (لا تحتاج لمسه)
  css/style.css   التصميم (لا تحتاج لمسه)
  assets/         الشعار، الصور، الخطوط

--------------------------------------------------------------
1) تعديل الأسعار أو إضافة/حذف باقة
--------------------------------------------------------------
افتح js/data.js وعدّل داخل packages لأي فرع. مثال إضافة باقة:

  { name: "الباقة الصيفية", price: 300, unit: "ريال / شهر",
    sessions: "16 حصة تدريبية", note: "4 أيام في الأسبوع", featured: true },

featured: true تضيف شارة "الأكثر توفيراً" وإطاراً أحمر.
احفظ الملف وارفعه مكان القديم — يتحدث الموقع فوراً.

وبنفس الطريقة تعدل: الأرقام، رسائل واتساب، التقييمات،
الإنجازات (STATS)، الأسئلة الشائعة (FAQ)، واللاعبين (PLAYERS).

--------------------------------------------------------------
2) تفعيل بكسلات التتبع (سناب / تيك توك / ميتا)
--------------------------------------------------------------
في أعلى كل ملف HTML يوجد مكان معلّم بتعليق واضح:
  <!-- [Snap Pixel] ألصق كود Snapchat Pixel هنا -->
ألصق كود التثبيت من منصة الإعلانات في المكان المخصص
في الصفحات الثلاث، وستُسجَّل أحداث "Contact" تلقائياً
عند كل ضغطة اتصال أو واتساب (الكود جاهز في js/main.js).

--------------------------------------------------------------
3) الرفع والنشر
--------------------------------------------------------------
الموقع ثابت (Static) ويعمل على أي استضافة:
  • الأسرع مجاناً: Netlify — اسحب المجلد كاملاً إلى netlify.com/drop
  • أو: Cloudflare Pages / Vercel / GitHub Pages / أي استضافة عادية
بعد حجز الدومين اربطه من لوحة تحكم الاستضافة.

--------------------------------------------------------------
4) إضافة فرع جديد مستقبلاً
--------------------------------------------------------------
  1. في js/data.js انسخ كائن فرع كامل داخل BRANCHES وعدّل بياناته
     (المعرف، الاسم، الرقم، الإحداثيات، الباقات...).
  2. انسخ ملف nuzhah.html باسم جديد وغيّر فيه فقط:
     data-branch="المعرف-الجديد" في وسم <body>.
  3. سيظهر الفرع تلقائياً في الصفحة الرئيسية ولوحة اختيار الفرع.
